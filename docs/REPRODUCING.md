# Reproduce HIV-ShiftGuard

## Windows 11

1. Download and extract the repository; Python and internet access are needed for a fresh run.
2. Double-click **`RUN_ALL.bat`** in the repository root. It creates `.venv`, installs dependencies, checks the code and downloads the four original Stanford HIVDB research files.
3. Open `results/latest_report.html` after the complete run. Run the same BAT again to resume interrupted tasks.

The model uses **CPU-only scikit-learn**, so a GPU is not required. Configuration is in [`config.json`](../config.json).

## Verify archived manuscript numbers without retraining

```bash
python scripts/verify_results.py
```

The committed results are a **snapshot of the completed 3 November 2026 run** (`42374487aabb5e1a`), not simulated data. The manuscript summarizes 67 eligible experiments, 23 drugs, and 32,313 measured drug–isolate pairs. The original run's source-code, raw-data hashes, seeds, and processing information are recorded in [`results/PROVENANCE.json`](../results/PROVENANCE.json).

## Evidence, boundaries and artifacts

- Public repository: source code, aggregate CSVs, provenance, figures, Word manuscript and PDF preview.
- Excluded: original downloaded Stanford files, per-observation predictions/split assignments, model `.joblib` checkpoints, and machine-specific logs. Avoid sharing raw downloaded data or potentially identifying research records without checking usage conditions.
- Resuming a **new** run works with local checkpoints generated by the pipeline. The public ZIP does **not** include the earlier trained models, so a first run retrains.
- `Table_09_All_Heldout_Predictions.csv` is intentionally omitted from the public summary. Regenerate it locally by running the pipeline; keep raw and record-level outputs private unless permitted.
- This is retrospective *in vitro* susceptibility estimation, **not** a medication-selection service, clinical outcome predictor, or cure discovery method.

Full methods: [`RESEARCH_PROTOCOL.md`](RESEARCH_PROTOCOL.md). Data source: [Stanford HIVDB](https://hivdb.stanford.edu/pages/genopheno.dataset.html).
